막히는 부분이 생기면 먼저 아래 내용을 확인해 주세요.

이미 다른 사람이 만든 계정이나 페이지가 있어요.

새로 만들지 마세요. 기존 소유자에게 사업주 계정을 소유자 또는 전체 관리자로 추가해 달라고 요청합니다. 중복 페이지와 중복 플레이스는 고객 리뷰와 광고 이력이 나뉠 수 있습니다.

담당자에게 전체 관리자 권한을 줘야 하나요?

아닙니다. Google은 전체 사용자, 네이버 광고는 운영 권한, Meta는 할당된 자산의 부분 권한이면 보통 충분합니다. 소유자·마스터·결제 권한은 사업주가 유지하세요.

광고는 계정을 만들자마자 시작되나요?

아닙니다. 계정 생성, 결제수단 등록, 캠페인 작성은 서로 다른 단계입니다. 광고 문구·대상 지역·월 예산을 사업주가 최종 승인한 뒤에만 집행합니다.

담당자와 계약이 끝나면 어떻게 하나요?

각 서비스의 사용자·권한 메뉴에서 담당자 권한만 제거하면 됩니다. 사업주 계정과 사업주 소유의 광고계정, 페이지, Pixel, 검색 데이터는 그대로 남습니다.
